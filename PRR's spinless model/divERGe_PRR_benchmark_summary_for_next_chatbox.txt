# divERGe kagome TUFRG PRR benchmark: summary for next chatbox

This note summarizes what we learned while trying to reproduce, at small scale, the PRR kagome TUFRG result with divERGe. It is intended as in-context learning material for a future chatbox.

The user’s final goal is not to reproduce PRR perfectly. The real goal is to study the same kagome extended Hubbard model after adding Kane-Mele spin-orbit coupling (NN and NNN types). The PRR reproduction work is a control benchmark to make sure the divERGe model construction, channel interpretation, q-resolved output, and diagnosis framework are understood before adding SOC.


================================================================================
1. Big picture: what has been achieved
================================================================================

We built a small-scale divERGe TUFRG setup for the kagome extended Hubbard model at the upper van Hove filling. The calculation uses:

    n_orb = 3
    SU2 = True
    n_spin = 1
    mu = 0
    filling = 5/12
    hopping amplitude in the Hamiltonian effectively chosen so that the middle band has E(M)=0

The calculation is not PRR-scale. It is a small-mesh qualitative benchmark.

What we can honestly claim now:

    We qualitatively reproduced the PRR channel / momentum-sector competition on a small mesh:

        U-dominant points -> q=0 magnetic / FM-like tendency
        V-dominant points -> q=0 A1 superconducting tendency
        mixed U,V points -> finite-M charge sector enhancement

At the form-factor level:

    FM is clean onsite A1-like.
    A1-SC is clean onsite A1-like in the representative V-dominant cases.
    The leading M-charge mode in this small run is CDW-like / onsite-dominated.
    However, after projecting out onsite-CDW components, the residual M-charge subspace contains clear NN-bond-rich cBO-like form factors.

So the faithful claim is:

    “We qualitatively reproduce PRR’s FM / A1-SC / finite-M charge-sector competition on a small mesh. The cBO-like bond form factors appear in the onsite-CDW-projected finite-M charge subspace, but the leading finite-M charge mode at this small size is CDW-like.”

Do not claim:

    “We fully reproduced the PRR phase diagram.”

Do not claim:

    “cBO is the leading M-charge mode in this small run.”


================================================================================
2. Noninteracting kagome model: sanity checks passed
================================================================================

We explicitly checked the noninteracting model before trusting the flow.

The required PRR-style upper van Hove point is:

    mu = 0
    filling = 5/12
    M points are saddle points of the middle band

The preflight noninteracting check printed:

    estimated_filling ≈ 0.41667 = 5/12
    E_mid(M1), E_mid(M2), E_mid(M3) ≈ 0
    |grad E_mid(M_i)| ≈ 0
    Hessian eigenvalues have opposite signs at each M point

So the upper VHS / higher VHS noninteracting setup is correct.

The M points are in reduced reciprocal coordinates, not Cartesian coordinates:

    Gamma = (0, 0)
    M1    = (1/2, 0)
    M2    = (0, 1/2)
    M3    = (1/2, 1/2)

Here (1/2,0) means half a reciprocal lattice vector, i.e. (1/2) b1.

For the 12 x 12 bosonic q mesh used in the small run, the q indices are:

    Gamma: iq = 0
    M1:    iq = 6
    M2:    iq = 72
    M3:    iq = 78

The earlier mistake was to divide q indices by nk*nkf = 36 instead of nk = 12. The bosonic q mesh in O.dvg is the coarse 12 x 12 mesh, not the fine 36 x 36 loop mesh.


================================================================================
3. Bare interaction M-degeneracy check passed
================================================================================

We also checked the bare density interaction at the three M points without invoking expensive divERGe postprocess.

For U=0.5, V=1.0, the bare density interaction matrices V_ab(M_i) have identical spectra at M1, M2, M3:

    eigvalsh[Hermitian V(M)] = [-1.5, 0.5, 2.5]
    singular values          = [2.5, 1.5, 0.5]

Relative spread across M1/M2/M3 was ~1e-16.

The dominant off-diagonal bond pair selected by each M point was:

    M1 -> AC
    M2 -> AB
    M3 -> BC

This is physically consistent with the three C3-related M points selecting different kagome bond sectors.


================================================================================
4. divERGe output structure: what O.dvg contains
================================================================================

For the TUFRG projected-channel run, O.dvg contains q-resolved channel data.

Important fields:

    Pchannel shape = (1, n_orbff, 1, n_orbff, nq)
    Cchannel shape = (1, n_orbff, 1, n_orbff, nq)
    Dchannel shape = (1, n_orbff, 1, n_orbff, nq)

    pploop shape   = (1, n_orbff, 1, n_orbff, nq)
    phloop shape   = (1, n_orbff, 1, n_orbff, nq)

In the projected run:

    nq = 144 = 12 x 12
    n_orbff = number of TU form factors; in the projected run this was about 141.

The TU basis index alpha corresponds to real-space/orbital form-factor data:

    alpha = (R, o_from, o_to)

The mapping is stored in:

    mi_to_R
    mi_to_ofrom
    mi_to_oto

This is the main difference from the user’s old band-basis N-patch code. In the old code, the leading eigenvector was a scalar patch vector v_i. In divERGe TUFRG, form factors live in orbital/real-space TU basis, not scalar patch basis.


================================================================================
5. Important correction: S_charge/S_mag/S_sc are only q=0
================================================================================

A major misunderstanding was cleared up by reading divERGe source code.

The fields:

    O.S_sc
    O.S_mag
    O.S_charge

come from divERGe function:

    lingap_ff()

The source comment says:

    // only calculates q = 0 linearized gap

Therefore:

    O.S_sc      is q=0 SC linearized gap output.
    O.S_mag     is q=0 magnetic linearized gap output.
    O.S_charge  is q=0 physical charge linearized gap output.

They are NOT q-resolved over all momenta.
They cannot be used directly to diagnose M-point CBO/SBO.

This was one of the most important corrections.


================================================================================
6. What “linearized gap” means here
================================================================================

In divERGe, “linearized gap” is not only superconducting gap. It means the linearized order-parameter equation for a channel:

    Delta = K L Delta

where:

    K = channel interaction kernel
    L = loop / bubble
    Delta = form factor / order parameter vector

The singular/eigenvalue strength tells the tendency toward an instability, and the vector gives the form factor.

This is conceptually analogous to the user’s old instability.py:

    old code builds bubble weights B
    constructs a bubble-dressed operator like s * B^{1/2} K B^{1/2}
    diagonalizes it
    uses sign-aware interpretation and projections such as q=0 uniform charge projection

Difference:

    old code: scalar band-patch basis
    divERGe: TU form-factor/orbital basis
    divERGe built-in S_*: only q=0


================================================================================
7. Physical channel construction in divERGe
================================================================================

Another key misunderstanding was cleared up from source code.

For SU(2) TUFRG:

    magnetic channel = C
    physical charge channel = 2D - C
    superconducting channel = P

In lingap_ff(), divERGe explicitly constructs physical charge as:

    2 * D_projection - C_projection

So:

    S_mag     = SVD/eigen-like diagnosis of C(q=0) * ph_bubble(q=0)
    S_charge  = SVD/eigen-like diagnosis of (2D-C)(q=0) * ph_bubble(q=0)
    S_sc      = SVD/eigen-like diagnosis of P(q=0) * pp_bubble(q=0)

The default solver mode was:

    tu_lingap_solver_mode = "sss"

So divERGe uses SVD for these q=0 outputs. Therefore S_sc is a nonnegative singular value; do not apply the old “negative PP eigenvalue = attraction” logic to O.S_sc.

However, if one directly analyzes raw Pchannel eigenvalues, sign conventions still matter. Do not confuse raw channel decomposition with built-in S_sc.


================================================================================
8. Projected-channel output: why we reran with tu_channel_calc_project = -1
================================================================================

Another important issue: the saved q-resolved P/C/D channels are not automatically the same objects as the projected channels used inside lingap_ff().

Source code shows:

    if tu_channel_calc_project = 0:
        save internal Pch/Cch/Dch

    if tu_channel_calc_project != 0:
        save P_projection/C_projection/D_projection based channels

For SU(2), when:

    tu_channel_calc_project < 0

then divERGe saves the D channel as the physical charge combination:

    D_saved(q) = 2D(q) - C(q)

and it flips the C channel sign:

    C_saved(q) ~ -C(q)

Therefore we reran with:

    cfg.tu_channel_calc_project = -1

This projected-channel run is the one to use for PRR-style q-resolved form-factor diagnosis.

In the projected output, the interpretation is:

    charge channel at q: K_charge(q) = D_saved(q)
    magnetic channel at q: K_mag(q) = -C_saved(q)
    SC channel at q: K_sc(q) = P_saved(q)

Do NOT compute 2D-C again from the projected output; D_saved already is 2D-C.


================================================================================
9. Pval/Cval/Dval vs S_*: do not confuse them
================================================================================

Source code `_save_channel_leading_ev()` showed that:

    Pval/Cval/Dval
    Pvec/Cvec/Dvec

are per-q decompositions of the channel matrix itself.

They do NOT include bubble / loop dressing.

So:

    Pval/Cval/Dval != linearized instability eigenvalues
    Pvec/Cvec/Dvec != loop-dressed instability eigenvectors

They are useful for form-factor decomposition of q-resolved projected channels, but they are not identical to S_sc/S_mag/S_charge.

The earlier attempt to reconstruct S_* from saved Pchannel/Cchannel/Dchannel and loops did not fully match, especially for SC and charge. This is not necessarily a bug: the saved q-resolved channel objects and lingap_ff internal projected products are not exactly the same representation.

Practical conclusion:

    Use S_* only for q=0 built-in divERGe linearized gap diagnosis.
    Use projected P/C/D q-resolved channels for sector/form-factor analysis at Gamma and M.
    Treat q=M diagnosis as channel/form-factor diagnosis, not exactly the same as divERGe built-in q=0 S_*.

================================================================================
11. Form-factor diagnosis results
================================================================================

The form-factor inspector analyzed leading Pvec/Cvec/Dvec components in the TU basis:

    alpha = (R, o_from, o_to)

It computed:

    onsite weight
    NN-bond weight
    longer-range weight
    onsite A1 overlap
    NN A1 overlap
    top components

FM:

    Gamma magnetic in U-only cases is onsite-A1 dominated.
    Example: onsite weight ~0.998, onsite pattern abs ~ (0.577, 0.577, 0.577).

This is the TU-basis version of “constant form factor” in the old band-basis mindset.

A1-SC:

    Gamma SC in representative V-only / large-V cases is onsite-A1-like.
    Example: onsite weight ~0.88-0.89, A1site ~0.88-0.89.

M-charge leading mode:

    Leading M-charge mode is onsite/CDW-like, not cBO-like.
    Typical results:

        onsite weight ~0.96-1.00
        NN-bond weight ~0.00-0.01

    Its onsite patterns look like finite-M CDW patterns, such as:

        M1: (A,B,0)
        M2: (A,0,C)
        M3: (0,B,C)

Thus the leading M-charge mode is CDW-like on this small mesh.

Subleading / residual M-charge:

    After projecting out onsite CDW subspace, the residual M-charge modes become NN-bond-rich.

Examples:

    U0p5_V1p0 residual mode:
        onsite = 0
        NN bond weight ~0.466

    U1p0_V1p0 residual mode:
        onsite = 0
        NN bond weight ~0.481

So cBO-like bond form factors are present in the finite-M charge sector, but they are subleading / appear after onsite-CDW projection.

Important wording:

    “cBO-like bond-rich finite-M charge form factors appear in the onsite-CDW-projected residual subspace.”

Avoid saying:

    “cBO is the leading M-charge order in this small run.”


================================================================================
12. Relation to PRR and what should be claimed
================================================================================

The small run qualitatively reproduces PRR at the benchmark/control level:

    U-dominant -> FM-like
    V-dominant -> A1-SC-like
    mixed U,V -> finite-M charge sector with cBO-like residual bond form factors

But the leading M-charge mode is CDW-like. This is not necessarily wrong: PRR itself has both CDW and cBO phases, and small patch size / end-flow treatment / truncation can bias the leading mode.

Faithful statement:

    “At mu=0 corresponding to the 5/12 upper van Hove filling, our small-scale projected TUFRG calculation qualitatively reproduces the main channel competition reported in PRR: U-dominant interactions enhance q=0 magnetic/FM-like modes, V-dominant interactions enhance q=0 A1 superconducting modes, and mixed U,V interactions enhance the finite-M charge sector. At the form-factor level, FM and A1-SC are clean onsite-A1. The leading finite-M charge mode is CDW-like at this small size, while cBO-like NN-bond-rich form factors appear in the onsite-CDW-projected residual M-charge subspace.”

This is enough to pause the PRR reproduction work and move on to the actual SOC project.


================================================================================
13. Why we should pause PRR reproduction now
================================================================================

The PRR reproduction was meant as a benchmark, not the final project.

We have now verified:

    correct kagome geometry and mu=0 VHS
    correct 5/12 filling
    correct three-M degeneracy
    divERGe TUFRG pipeline runs
    physical channel convention is understood
    q=0 built-in S_* scope is understood
    q-resolved projected channel output is understood
    form-factor diagnosis in TU basis is implemented

Further work to make cBO leading would likely require:

    larger mesh
    more PRR-like flow parameters
    more careful stopping-scale treatment
    parameter tuning
    possibly larger form-factor cutoff

This would be a rabbit hole relative to the real goal: adding Kane-Mele SOC and studying whether the instability structure qualitatively changes.

Recommendation:

    Pause PRR reproduction now.
    Treat it as a validated baseline.
    Move to adding SOC.


================================================================================
14. Next scientific goal: Kane-Mele SOC
================================================================================

The user’s real target is the same kagome extended Hubbard model but with additional Kane-Mele SOC:

    NN Kane-Mele SOC
    NNN Kane-Mele SOC

In the user’s old band-basis N-patch code, adding SOC gave interesting qualitative changes, e.g. FM order being replaced by charge loop-current-like order. This is more than a phase-boundary shift; it suggests a drastically different instability landscape.

The next divERGe stage should test this seriously.

Key issue:

    Kane-Mele SOC generally breaks full SU(2), though it may conserve S_z.

Therefore, we must decide whether the divERGe calculation can still use:

    SU2 = True, n_spin = 1

or must switch to explicit spin:

    SU2 = False, n_spin = 2

For honest SOC physics, especially spin anisotropy / charge current / spin current distinction, explicit spin is likely needed.

The next chatbox should not blindly use the SU2-reduced setup for SOC without checking this.


================================================================================
15. Diagnosis philosophy going forward
================================================================================

For the old band-basis N-patch code, the diagnosis levels were:

    Level 1: channel / momentum sector instability
    Level 2: scalar patch candidate overlap
    Level 3: orbital/bond/current fingerprint reconstruction

In divERGe TUFRG, the analogous structure should be:

    Level 1:
        q and physical channel sector:
            P, C, 2D-C
            Gamma, M1, M2, M3

    Level 2:
        TU form-factor decomposition:
            onsite vs NN bond vs longer-range
            A1 / E / bond-rich / onsite-CDW-like classification

    Level 3:
        real-space pattern / current fingerprint:
            site charge/spin
            real bond order
            imaginary bond current
            spin current if explicit spin is included

Important limitation:

    Level-3 fingerprint is not a new susceptibility calculation.
    It is a postprocessing interpretation of the eigenmode/form-factor direction.

This is consistent with the user’s old Level-3 philosophy: if an eigenmode condenses, use its direction to reconstruct an orbital/bond/current pattern. It is a mean-field-like fingerprint, not a direct many-body expectation value.


================================================================================
16. Common mistakes / misconceptions resolved
================================================================================

Mistake 1:
    Treating O.S_charge/S_mag/S_sc as q-resolved over all transfer momenta.

Correction:
    They are only q=0. CBO/SBO at M require q-resolved projected channels.

Mistake 2:
    Thinking S_charge/S_mag/S_sc are raw eigenvalues with signs like old code.

Correction:
    Default solver mode is SVD, so S_* are nonnegative singular values for q=0 linearized gap problems.

Mistake 3:
    Reconstructing physical charge as 2D-C from projected output.

Correction:
    With tu_channel_calc_project=-1, D_saved is already 2D-C. Do not compute 2D-C again.

Mistake 4:
    Confusing q mesh with fine loop mesh.

Correction:
    O.dvg q dimension is coarse nk x nk = 12 x 12, not nk*nkf x nk*nkf = 36 x 36.

Mistake 5:
    Expecting band-basis scalar “constant form factor” language to carry over directly.

Correction:
    In TUFRG, constant/FM/A1 is expressed as onsite sublattice-uniform form factor in (R,o_from,o_to) space.

Mistake 6:
    Calling leading M-charge cBO just because it is M-charge.

Correction:
    Need form-factor analysis. In our small run, leading M-charge is CDW-like; cBO-like bond modes appear after onsite projection.

Mistake 7:
    Assuming PRR reproduction requires perfect cBO leading mode on small mesh.

Correction:
    For a benchmark, sector-level reproduction plus cBO-like residual form factor is enough. The real project is SOC.
